An entry for make.fun's **One Emoji, One Smile** bounty: send exactly one
emoji, the one most likely to make a stranger smile.

## The entry

`main.py` (Python 3.13 standard library only, deterministic, no network, no
randomness) writes exactly one emoji to `/output/entry.txt`:

**🫶 — heart hands (U+1FAF6)**

Two hands forming a heart: an active gesture of sending warmth. It reads as
kind and friendly at first glance, needs no context, is understood the same
way by a stranger of any age or background, feels deliberately chosen rather
than the first smiley that comes to mind, and sends kindness platonically —
no hug, no kiss, no flirtation, nothing that would read oddly from someone
unknown.

## Run it

```sh
python3 main.py        # writes /output/entry.txt
```
